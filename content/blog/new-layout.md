## AG-web-2.0

The original website was written by hand with what AG thought to be clever design and... well, design might have been clever but it was not usable on any screen under 4k or using 16:9 proportions. For a remodelling we opted for a 
less top heavy look and moved hero animation to it's own intro that obstructs the view once and gets out of the way. Menu panel had some improvements to squeeze less and hold more (we are 69 pages deep here). Dripping candy font was removed from H2 headings since it wasn't resistant to resizing and required individual per page adjustments for mobile view. 
New look is already available on Github: https://github.com/annoyinggoods/AG-website 

###  AGRr!
Building a website really makes one go Grr! and ugh... We literally just done that. So for the sake of us and others this website has only the animated parts unique. All the rest is built using our reusable scripts that will come in AGRr! visual web design tool. Think Lovable but offline. Massive amount of predefined scripts accumulated over last 6 years of coding that suit almost all instances we could think of. That is not to say we are capable of thinking of everything, but if THOUSANDS of non-repeating scripts are not enough for your use case- we may add more later. 

Soon we will publish exactly how to build a clone of this website using the tool step by step. 

###  AGRr! vs AI
As with most of our products AI has an access and can be used but it's not a core of the product and is generally not needed to get full benefits. However if you don't know how to code, hate JavaScript or just never done this before and want a helping hand of a dedicated cyber minion the chat is there- LLM will have an access to tools driving the app and to write code for highly particular needs not possible to achieve with plain compositor. Whether you're all for our AI overlords or anti-slop-warrior this will work for you just fine.
