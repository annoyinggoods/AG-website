        Guide
        

        Headings run from H2 to H6. The page already owns the H1, so the body starts at level two.
        

        Use bold and italic for emphasis.
        

        Every image needs a description, because the description becomes the alt text: ![A short description](assets/pictures/name.webp "800x450")
        

        The size after the path is optional and keeps the page from jumping while the picture arrives.
        

        An excerpt replaces the first forty five words on the index card. A standfirst and an author note appear on the detail page.

        The panel exports the exact command, so a release can go out from a plain PowerShell window. The password travels in the AG_DEPLOY_PASSWORD environment variable and never in the command line.
