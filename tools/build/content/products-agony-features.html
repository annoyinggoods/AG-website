Features

Five things carry the AGony desktop, and each has its own page with a recording of the real thing in motion. The recordings were captured through a real terminal on a real machine — what you see moving is the actual desktop, not an artist's impression.

The five

The command bar

One bar, Ctrl-K, and the terminal starts finishing your sentences: apps, run history, file paths and shell completions for around a thousand commands, and nothing runs until you press Enter.

Windows and the taskbar

Real windows with titlebars: drag to move, drag the bottom or right border to resize, minimize to taskbar buttons, maximize to fill the desktop. Close the desktop and the shells keep running.

The start menu

Four roots — SEARCH, FILE MANAGER, PROGRAMS, SETTINGS — a filter that ranks as you type, and an app directory that installs curated terminal apps through their own recipes.

The file panel

A gitignore-aware tree docked beside your shells, with fuzzy search, and a drag-and-drop paste menu that shows the exact text a dropped path will insert.

Settings and themes

Three built-in themes with per-role recoloring that refuses low-contrast picks, live preview until Apply, key rebinding with collision checks, and an ASCII mode for terminals without the icon font.

Beyond the five

Smaller pleasures round it out: a first-run welcome that names the three things to try, a THANK-YOU.md that lands on the desktop crediting every dependency, a taskbar clock, desktop tiles for pinned apps and documents, and a doctor command that reports the environment without ever touching it.
