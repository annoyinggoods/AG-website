The two free prerequisites

The rmux engine — required

AGony is a tenant on the rmux multiplexer engine, which owns the terminal plumbing and your process tree. It is free, open source, and installed with cargo install rmux (Rust's installer puts it on your PATH). AGony starts and manages the engine's daemon for you — connect if one is running, start one if not — you never operate it by hand.

The carapace completion binary — recommended

The command bar's completions come from carapace-bin, a free, open-source completion engine. Install it any way you like — scoop, winget or its GitHub release — and AGony finds it on PATH, or point the AGONY_CARAPACE environment variable at it. Without it the desktop works completely; only the command suggestions go quiet.

Install in four steps

From the archive to the desktop

1. Unpack the archive — in PowerShell: tar -xzf agony-0.9.0-x86_64-pc-windows-msvc.tar.gz.

2. Put agony.exe somewhere on PATH, or run it from where you unpacked it.

3. Run agony doctor once — it reports the environment (the engine, the daemon, the completion binary, your font's icon support) and never repairs anything.

4. Run agony in Windows Terminal. The desktop opens with a welcome window naming the three things worth trying.

Optional: agony selftest proves the whole hosting chain — a real daemon, a real pane, render, input and resize — before your first session. Your settings, history, themes and installed apps live under %APPDATA%\agony\ and survive updates.

Good to know

AGony has no telemetry, no accounts and no network calls of its own. The one network feature — the app directory fetching its curated catalog — degrades silently to the bundled seed when offline, and tells you so on a status line. Building from source is equally plain: it is Rust and Cargo, and the license is open source with ethical restrictions.
