AGDevelop

The studio workbench

AGDevelop is planned as the internal toolkit the studio uses to build the other tools: the build that assembles these pages, the menu tree that feeds the navigation, and the local index the demo reads from. It is aimed at people who want to work on the studio's own machinery rather than on the products. The copy is not written yet, so this page stays a shell until the shape of the tool is agreed.

Status: announced

If you already have a use case for it, send us a feature request and we will read it before the tool is built.
