Windows and the taskbar

AGony windows are windows: a titlebar with the program's name, minimize, maximize and close buttons, a border you can grab. Drag a titlebar and the window moves; drag the bottom or right border and it resizes, and the shell inside reflows when you let go. Both clamp at the desktop's edges, so nothing can be dragged out of existence.

The keyboard half

Every window action has a combo

Ctrl-E cycles focus and the focused chrome visibly changes; Ctrl-M minimizes to a taskbar button — and a minimized window is never rendered until you bring it back; Ctrl-F maximizes to fill the desktop and again restores the remembered rectangle; Ctrl-W closes, ending that pane's program; a double-click on the titlebar maximizes and restores. The layout math is pinned by tests: focus is always the top of the stack, minimized windows never draw, rectangles stay inside the desktop, ids never repeat.

The taskbar

The taskbar carries the Start button, one button per open window, a prompt area with the focused pane's working directory, and a clock. Click a taskbar button: the focused window minimizes, a minimized one restores, another one takes focus. Prefer it at the top of the screen? One setting moves it, and the start menu and command bar follow.

Why windows in a terminal are worth it

If panes and splits confuse you

Overlapping windows with titlebars need no manual: you already know how they work from every desktop you have used. Nothing is hidden behind a chord you have not learned yet, and minimizing a window you are done with — instead of closing the shell inside it — means the program keeps its state under the taskbar.

If you live in a multiplexer already

Under the chrome this is the rmux engine: Ctrl-Q detaches rather than kills, the daemon owns the process tree, and a fresh run adopts the previous windows with their programs' console titles — the pattern you know from tmux sessions, wearing a titlebar. Closing one window ends that pane's program only; the anchor session keeps everything else alive, so restarting the desktop is instant.
