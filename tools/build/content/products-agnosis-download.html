The installer is the easy road: it asks where to put AGnosis, shows the README during the install, adds a Start-Menu shortcut, and offers to register the login autostart and start the daemon — the global hotkey works as soon as the daemon is up, and its uninstaller reverses all of it.

The portable archive is the no-install road: one self-contained binary with the font embedded inside it, so there is nothing to install next to it and no runtime assets to carry around. Unzip it anywhere and run agnosis.exe; without the daemon it is still the full parade, with the editor on F2, balloon folders, and the exporters — only the global hotkey needs the daemon behind it.

Run it

From the installer to the parade

1. Run agnosis-setup.exe, pick an install folder, and let it register the autostart and start the daemon on the finish page.

2. Press A + G + Shift + Space to summon the parade and minimize the browsers, and press ESC or the same chord again to send it home.

3. F1 opens the full README in the app, and F2 opens the drawing editor straight from the parade.

From the archive to the parade

1. Unpack the archive — in PowerShell: Expand-Archive -Path {{agnosis_file}}. You get an agnosis folder with the binary and the licence in it.

2. Run .\agnosis.exe. The parade takes over the screen straight away; a note on the input line reminds you when the daemon is not running, because the hotkey is the daemon's.

3. For the hotkey without installing, .\agnosis.exe start runs the hotkey listener in the background, .\agnosis.exe stop stops it, and .\agnosis.exe install makes it start with Windows.

The commands

  • agnosis.exe — the parade, immediately.
  • agnosis.exe start and agnosis.exe stop — the background hotkey listener.
  • agnosis.exe install and agnosis.exe uninstall — the hotkey starts with Windows, or stops doing so.
  • agnosis.exe add <image> — turns a picture into a balloon that marches with the parade.
  • agnosis.exe export loop.html — exports the parade as a self-contained web page; .gif writes an animated GIF, any other extension writes an art package.
  • agnosis.exe selftest --frames 2 — renders the parade headless and writes the frames as pictures, which is the honest way to check a build.

Before you double-click

Good to know

  • No console window. The binary is a GUI program, so nothing flashes on the screen when you run it.
  • Nothing is closed. Browsers are minimized, never closed, so no tab and no half-filled form is ever lost.
  • Nothing leaves the machine. There is no account, no cloud, no telemetry and no update check. The parade fetches nothing from anywhere.
  • Your settings live in a plain file. config.toml sits beside the balloons folder, and the parade reads it while it runs.

Where the source is

AGnosis is a Rust workspace under the Annoying Goods Open Source License with Ethical Restrictions. The simulation sits in a pure platform-free core and a second front end runs the same code in a browser tab, so the web parade cannot drift from the native one. The product page tells more about the parade itself, and the bug form lands on the workbench if the ducks misbehave.
