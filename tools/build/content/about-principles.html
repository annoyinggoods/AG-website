Principles

Simple, verbose, human-readable code.

Plain HTML, CSS, and TypeScript with no frameworks for web and web-adjacent apps.

No show-off complex code for other coding languages.

Small focused files with one clear job each.

Accessibility is not optional: semantic markup, keyboard paths, and readable contrast. If you find us lacking here please let us know!

Desktop and mobile together

For AG website we designed both layouts at the same time.

Mobile was never an afterthought even if our products are mostly for desktop. This is what CompSci taught and this is what we know now. It would feel weird to do it any other way...

All is fun and all is learning

You live, you laugh, piff-paff.

All our code was written because curiosity took a better of us, because we didn't find an equivalent with the same functionality for free or because we wanted to learn Python and then learned what a scope creep really is. Please bear in mind most of the software here started development between 2021 and 2025, so if someone beat us to releasing, it's on them, not on us. We rush the work only when we feel like the time is right, planetary systems are aligned adequately and our energy levels are just about right.
