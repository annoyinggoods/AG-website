GitHub

The source is public

The studio keeps the source of this site in a public repository. Read it, copy it, check what it does with your data, or run it on your own machine.

Issues can be reported through the bug form. The studio reads every one of them, and a report does not need an account anywhere.

Where things live

  • The site itself. One folder per page, each holding its own index file, so every address ends in a slash and every page is a plain file on disk.
  • styles/ One stylesheet per concern. Layout, boxes, menus, motion, and long form content each live in their own file.
  • src/ The TypeScript that runs in your browser, one module per job. It compiles into scripts/ and stays optional. Every page reads without it.
  • tools/ The build, the deploy helpers, and the menu tree that generates the navigation, the search index, and the sitemap.
  • wasm/ A small Rust crate that compiles to WebAssembly. It does the text statistics for the chart demo, on your machine, with no server involved.
