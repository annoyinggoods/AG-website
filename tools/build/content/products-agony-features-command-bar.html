The command bar

Press Ctrl-K — or click the taskbar's status area — and a bar drops in along the taskbar edge with the focused pane's working directory at the left. Type, and suggestions appear before you finish the word. Press Enter to accept one; press Enter again to run it in a new window.

Where the suggestions come from

Four sources, one ranked list

The bar merges everything it knows: the app catalog (installed apps and launchable entries), your run history (previous lines, ranked above the rest, with a ✗ marker on commands that failed), the file panel's current tree, and shell completions from the carapace completion binary — which knows roughly a thousand commands and their arguments. Type git che, get checkout; type the first letters of an app, get the app.

When exactly one candidate remains, Ctrl-F autofills it. The wheel scrolls the list; a click selects; a double-click accepts. Only Enter ever runs anything — a suggestion is text until you commit to it.

The drop: files without typing paths

Grab a file in the panel with g, then press Ctrl-G over the bar: a paste menu opens offering the file as a name, as an absolute path, or as a path relative to the bar's working directory. Each row shows the exact text it will insert, so what you see is precisely what lands — quoted, at the cursor. The file panel page shows that menu in motion.

Who it is for

If commands do not stick in your head

The bar means you never have to remember a flag, a subcommand or a path spelling. Start typing what you think the command is; the ranking forgives typos and fragments. Wrong guesses cost nothing because nothing executes until Enter — the terminal stops being a place where a mistake runs something.

If you already know your commands

The bar is a launcher, not a replacement shell: Enter runs the line in a new window, the history is persisted where you can read it (agony history prints it, --clear empties it, the file lives in your AGony config directory as valid JSON even after a hard kill), and completions arrive through carapace as a subprocess with a timeout — the desktop never blocks on it, and the bar works without carapace installed, just quieter.
