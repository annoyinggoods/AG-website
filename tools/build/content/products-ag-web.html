The site you are reading

AG-web is the Annoying Goods website itself — the pages, the menu, the spider and the search are all this one product. It is listed here because its stack is a statement: the whole public site is dependency-free HTML and CSS, with no framework anywhere in what a visitor downloads.

The basic stack

HTML and CSS carry the layout, the theming and the glass. TypeScript is allowed for logic and compiles down to plain JavaScript modules that the build bundles by hand — no bundler framework, no runtime dependencies. Rust and WebAssembly enter only where the project genuinely needs WASM, and nowhere else.

Node.js is a development-only guest: it runs the build scripts and the local admin panel helper, and it must never ship to production or run on the public site. The deployable output is plain files.

The house rules

No frameworks unless one is argued for and agreed. Files stay small and single-purpose. Every page must be easy to extend and must meet accessibility requirements: semantic HTML, ARIA where it is needed, keyboard navigation and colour contrast. Desktop leads the design, and the mobile layout is built at the same time, not after.

The build assembles every page from a navigation tree, per-page metadata and content fragments, then validates titles, links, images and the content security policy before anything is allowed to ship.

Hosting and source

Served from IONOS

The site is served on IONOS from a folder bound to the domain, under the path /annoyinggoods. The build produces the deployable bundle with content digests, a sitemap, a search index and a 404 page that shares the site chrome.
