MCP and External Tools

Sometimes the right helper lives outside the app. The Model Context Protocol (MCP) is an open standard — a shared plug socket, originally opened by Anthropic and now spoken by many tools — that lets AGIT hand small, clearly-scoped jobs to outside programs and get answers back.

The design rule is the one the whole studio runs on: you decide what connects. Tools are approved in Settings, they see the project you point them at, and nothing grants itself new permissions while you are not looking.

What MCP is, without the acronyms

A plug socket for helpers

An MCP server is a small program that offers specific abilities: "search this folder", "read this git history", "look this up in the dictionary service I run". AGIT — and increasingly the rest of the AI world — knows how to talk to anything that offers that socket. You add a server, AGIT lists what it offers, and the AI can call on those abilities when a job matches.

Practical examples researchers actually use: pointing a file-server at your sources folder so the AI can locate the right document itself; a git server over your manuscript's repository for "what changed since the version my editor saw"; your own translation or lookup service for the specialist terms in your field.

The boundary, stated plainly

Consent lives with you, not with the model

  • Tools are switched on by you, in Settings, one server at a time. The AI cannot enable a tool for itself.
  • Tool output lands in a dedicated canvas, visibly — not silently folded into your draft.
  • Project scoping holds: a helper works inside the project you pointed it at. A tool call cannot wander into another project's files by asking nicely.
  • Unplugged is the default. If you never configure a server, AGIT never talks to one. The writing features are complete without any of this.

The same philosophy covers the other doors: AI providers use your keys, sync uses your own cloud storage, and telemetry starts switched off. AGIT treats "it might phone someone" as a feature you turn on, not a default you turn off.

When you actually need this

Honestly? Later, maybe

MCP is plumbing, and plumbing is for the day you need it. Most writers never open this panel, and that is fine — it exists for the researcher with a custom index, the worldbuilder with a home-grown wiki, the team that keeps their lore in a git repository. When that day comes, the socket is already on the wall.
