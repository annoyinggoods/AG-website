Failed

The shelf, kept on purpose

Experiments that did not survive are archived here with a one line reason. A failed build is a result, not a shame, and it is usually cheaper to read the reason than to rebuild the thing.

Web shaker search

A search box that shook the whole page on every keystroke, as if the layout had done something wrong.

Post-mortem: motion belongs on the lens, not on the layout.

Thread count badges

Badges on every menu item showing how many loose threads each one held, counted from two different places.

Post-mortem: one source of truth lives in the menu tree.

Auto weaving hero

A hero animation that began weaving the moment the page loaded, whether the visitor wanted it or not.

Post-mortem: the gate click stays, and the spider waits for an invitation.

Silent sync

A plan to mirror a writer's local files into a studio account so drafts followed them everywhere.

Post-mortem: local first means local, and the copy was never asked for.

Why the archive stays

The shelf is kept deliberately, because a studio that forgets its mistakes repeats them. Nothing listed here is a product, and nothing listed here is a promise that the idea will return.

New experiments start on the prototypes page. If one of these ideas deserves another try, send a feature request and say why.
