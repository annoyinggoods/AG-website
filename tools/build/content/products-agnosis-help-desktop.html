AGnosis on the desktop — how to run it and use it

This page is for the desktop app: the hotkey that minimizes your browsers and fills the screen with ducks. It covers Windows, macOS and Linux — install, first run, every key, the editor, the config and the exports. If you only want the browser parade, read the in-browser guide instead; the full read-me carries every detail, and the download page has the files.

Install it

Windows — the installer (recommended)

  1. Download agnosis-setup.exe from the download page and run it.
  2. Pick an install folder (any folder; the default is fine) — the installer copies the app, adds a Start-Menu shortcut and shows the README.
  3. Tick login autostart and start the daemon now when asked. From that moment the global hotkey works; there is nothing else to set up.

Prefer no install at all? The portable zip needs no setup: unzip agnosis-<version>-windows-x64.zip anywhere and double-click agnosis.exe — the parade starts on the spot. What the portable exe cannot do is listen for a hotkey (that is the daemon's job), so you open and close the parade by hand.

macOS and Linux

macOS ships a .dmg: mount it and drag agnosis.app into Applications. The first launch is blocked by Gatekeeper (the app is unsigned): right-click → Open, or allow it once under System Settings → Privacy & Security ("Open Anyway"). Linux ships a .deb: sudo dpkg -i agnosis_<version>_amd64.deb puts agnosis on your PATH and in the application menu. A Wayland session needs XWayland (the app opens through it).

On macOS the global hotkey needs one permission: System Settings → Privacy & Security → Input Monitoring → add AGnosis → switch it on. The menu-bar item (the little duck in the menu bar) needs no permission — it starts the parade and the editor without any grant, and it is what agnosis install registers on a Mac.

Run it: press this, this happens

The hotkey and the parade

Press the hotkey — A+G+Shift+Space (Windows/Linux), Ctrl+Alt+Shift+Space (macOS)
Every open browser window minimizes and a fullscreen duck parade takes over the screen. The browsers are minimized, never closed — nothing is lost.
Press the hotkey again
The parade ends.
Esc
Ends the parade too.
When the parade ends
By default the browsers stay minimized — that is the joke, and you un-minimize them yourself. Want them back automatically? Set [browsers] restore_on_close = true in the config (or the editor's settings panel) and they return on their own.

The parade opens on the display your mouse is on (or the primary one — monitor in the config). It runs from the daemon; the hotkey works in any app, any time.

Every key while the parade runs

Click a duck
It hops, grimaces and clucks — and keeps marching.
Shift-click a duck
It stops in place; the ducks behind it stop, the ones in front keep walking.
Type a name + Enter
The input line under the grass adds a balloon: type the name of a picture in the balloons folder (redball), press Enter, and it flies in on the next carrier duck.
Ctrl+O
Opens the balloons folder so you can drop pictures into it.
F2
Opens the draw-your-own editor.
F1
Opens the built-in help — the full README, scrollable.
F12
Copies the current frame to the clipboard as a picture.

Draw your own duck

Open and close it

F2 in the parade, the Ctrl+Shift+D chord anywhere, or Draw Your Own in the macOS menu bar. The editor is a borderless window at 80 % of your screen — no title bar, no close button: Escape closes it (it closes an open dropdown first, then a panel, then the editor). The chord toggles it shut as well, and it never touches your browsers.

Draw and save

The top bar picks what you are drawing: the kind (BAL balloon, SPR walking duck, GRS grass tile, DEC a hat the ducks wear), the size (BIG/SML) and the frame count (1–4 poses — Enter stores a pose and shows it faintly behind the next). Click cells to paint, drag for strokes, pick from the 19 tools and 8 colours on the right, type a name, press SAVE. The asset lands in your drawn folder and is immediately listable.

Ctrl+Z / Ctrl+Shift+Z undo and redo a whole stroke. The editor also autosaves a draft a second after you stop drawing, and offers it back the next time it opens — a crash costs at most the last second.

Put your art into the parade

Click ASSIGN in the editor's top bar: the sixteen parade slots are on the left, your drawn assets of that kind on the right. Click a slot, click an asset — the status line reports ASSIGNED <SLOT> = <NAME> and the running parade swaps the art in live. CLEAR puts the built-in art back. The same panel covers the three look targets: GRASS (the ground tile), DECO BIG and DECO SMALL (the hats).

From a terminal instead: agnosis list-drawn prints your assets and agnosis assign SMALL3 myduck assigns one (--clear un-assigns).

Tune the parade — two ways

The settings panel: click CFG in the editor's top bar (or F1 in the editor). Every documented setting is a row — sliders, toggles, dropdowns, text fields. A change is written to your config file the moment you make it and the running parade picks it up within a second. RANDOMISE gives each of the eleven ducks its own personality; RESET takes it back.

The config file: everything also lives in config.toml (%APPDATA%\AGnosis\AGnosis\config\config.toml on Windows, ~/.config/AGnosis/config.toml on Linux, ~/Library/Application Support/com.agnosis.agnosis/config.toml on macOS). Edit it while the parade runs — the change lands live. agnosis config show prints what the app actually uses; agnosis config validate checks your file. A broken file never takes the parade down: the old values stay until you fix it.

Balloons, exports and the rest

Balloons, three ways

  1. Type the picture's name on the parade's input line and press Enter — ADDED <NAME> and it flies.
  2. Drop a picture (or a hand-made .ans file) into the balloons folder — Ctrl+O opens it — and the watcher mounts it without a restart.
  3. agnosis add picture.png copies any picture from anywhere on disk into the folder and converts it.

Balloons fill five slots on ducks 1, 3, 5, 7 and 9; a sixth picture replaces the oldest. Pictures become ASCII art at your screen's own size, so they are always in proportion.

Send it to somebody

agnosis export parade.html writes one self-contained page that replays your parade on any machine (no network, no assets, pausable). agnosis export parade.gif writes the animated GIF. agnosis export parade.agnosis writes a package of your art and look — the browser version imports the same package, and agnosis import reads it back on any machine. The exports are reproducible: the same parade exports byte-identical files.

The commands, in one breath

agnosis opens the parade at once; agnosis start / stop run and stop the daemon; agnosis install / uninstall register and remove the login autostart; agnosis add, assign, list-drawn and grass manage your art; agnosis config show / validate / reset / backup / export mind the configuration; agnosis preset save/list/use remember a whole look; agnosis export / import move creations between machines; agnosis shot and selftest write PNG frames. The full read-me documents every one.

Questions people actually ask

Does it close my browsers?

No — it only minimizes them. The browser keeps running, every tab and every half-typed form stays exactly as it was. When the parade ends the browsers stay minimized by default (that is the joke), and you bring them back yourself — or set [browsers] restore_on_close = true to have them restored automatically. Nothing is ever closed, so nothing is ever lost.

Does it support Linux and Mac?

Yes — Windows, Linux (X11; a Wayland session needs XWayland) and macOS. macOS asks for one permission, Input Monitoring, before the global hotkey can listen; the menu-bar trigger needs no permission at all and works even without it. The browser version on the playground page runs on every platform a modern browser runs on.

How do I assign my own key combination?

In config.toml, under [hotkey]: windows, linux and macos hold the parade chord, editor the draw-your-own chord. Write the keys joined with + — for example linux = "Ctrl+Alt+D". A chord may hold any number of keys (letters, digits, Space, Esc, F1–F20). The change lands without a restart: save the file and the daemon picks it up. Set editor = "" to switch the editor chord off; a chord that does not parse is reported and dropped, and the parade chord keeps working.

Do I need to install anything else to use this?

No. AGnosis is one self-contained binary — no runtime, no framework, no account, no network connection. The Windows installer carries the exe, the README and the licence; the portable zip is the same exe; the macOS app and the Linux package are just as complete. (Building it from source needs Rust, and the Linux build needs the ALSA and X11 development headers — but that is only if you build it yourself.)

Where can I report bugs and issues?

The studio's report-a-bug page reaches the workbench directly — describe what you pressed and what happened. Feature requests have their own door at request a feature. The source lives on GitHub, so an issue there works too, and the trace log (AGNOSIS_TRACE_FILE) is worth attaching when something misbehaves quietly.
