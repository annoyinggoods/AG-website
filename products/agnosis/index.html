Download AGnosis

What is this?

Someone walks in while your browser is open? AGnosis gives you a quick, silly curtain: press a hotkey, your browser windows minimize, and a fullscreen parade of ASCII ducks takes over. Press the hotkey again or Esc to end the parade. It is a joke with a practical little timing trick, not a privacy or security tool.

HIDE YOUR P*RN AND SHOW YOUR DUCKS.

It's fun, it's addictive and it's DUCKS.

What You Get

AGnosis is a desktop app that temporarily gets browser windows out of view without closing them. By default, it minimizes browsers and leaves them minimized after the duck parade ends, so they do not pop straight back onto the screen. You can enable automatic restore in the configuration if that suits you better.

The parade is customizable: set the sky and backdrop, add pictures as balloon art, show a message, or draw your own duck. AGnosis does not need an account, cloud service, or network connection. It is available as a Windows archive; macOS and Debian packages are listed as they are released. Check the download page for the current platform packages and version.

The app was built under the working name ducks, which described it perfectly. Studio names always have an 'AG' in them, so the ducks got religion: gnosis is knowing of things, the ducks know nothing of your browser history. They march. They practice agnosis. The working name still can be found around, which keeps the rename honest. You are reading the sales page; the ducks have not been informed.

A Bit More Technical?

What the hotkey actually does

AGnosis is a Rust desktop application that responds to a configurable global hotkey, minimizes recognized browser processes, and displays a borderless fullscreen ASCII animation. The default hotkey is A+G+Shift+Space on Windows and Linux, and Ctrl+Alt+Shift+Space on macOS. The parade appears on the display under the pointer, or on the primary display when configured.

Press the hotkey again, or ESC, and the parade packs up. The chord is one line in the config, and a chord can hold any number of keys.

Minimized, never closed

Browsers are minimized, not closed. Nothing is closed, so no tab, no half-filled form and no unsaved work is ever lost. The parade is a curtain, not a shredder.

A built-in process-name list covers more than twenty browsers: Chrome, Edge, Firefox, Brave, Vivaldi, Opera, Tor and friends, Thunderbird included. Users can add program names in configuration, and macOS matching can use bundle identifiers. Browsers only: the editor, the terminal and the spreadsheet stay exactly where they are.

By default the browsers stay minimized after the parade ends, because a screen that snaps back open is exactly the moment the joke exists to prevent. Automatic restoration is configurable and is not the default. The ducks will not judge you. Probably.

Eleven ducks and a physics problem

The scene is a fullscreen grid of character cells with a simulation underneath, drawn through your GPU. The two big ducks lead, nine small ones follow, and the five balloons hang on ropes with real pendulum physics, wobbling through a hundred and twenty substeps a second.

The sky is a gradient you can set by time of day. Up to three backdrop pictures scroll behind the parade at their own speeds. Every duck can wear a hat. Each duck can carry a personality of its own, bob, gait, phase and colour, and the one duck marching slightly out of step will be the one you love most.

The weather

The parade has weather, seeded and deterministic, so the same storm always falls in the same order.

Rain
Blue waves fill the gaps between the grass blades, and splashes bloom around every duck's feet.
Snow
The ground turns white and one chosen duck falls on its backside. Every duck behind it stops, in order, and keeps marching in place. The rhythm survives.
Wind
Every grass blade leans the other way.
Lightning
The tall blades flash, and the whole parade freezes for a second and a half. Then it resumes as if nothing happened.

The ducks notice you

Click a duck and it hops, grimaces and clucks. Shift-click one and it stops dead, the ducks behind it stop too, and the ones in front keep marching; the held duck keeps walking on the spot, because the rhythm is a clock, not a video.

Every sound is synthesized as it happens. No audio file ships, none is loaded, and a machine with no sound card simply marches in silence, unbothered. A note track can be composed in the editor and played in step with the marching, because a parade deserves a soundtrack.

Fully Technical

A pure core and its front ends

AGnosis is a Rust workspace with a platform-independent simulation core and native front ends. Its native renderer presents a fullscreen character-cell scene with deterministic seeded weather, duck movement, pendulum balloon motion, configurable gradients and backdrops, custom art, and synthesized audio. The same simulation core is used by the browser front end, so the web parade cannot drift from the native one — and that front end runs right here: run the parade online in the playground.

The browser match, precisely

The global hotkey minimizes matching browser processes without closing them. Matching uses a built-in list of more than twenty process names, user-configurable additional names, and macOS bundle identifiers. By default, browsers remain minimized after the parade; restoration can be configured.

Plain files, live reload

Configuration is stored in config.toml beside the balloons folder and supports live reload and a settings panel. Edit it while the parade runs and the change lands on screen within a second, no restart. Every write is surgical: your comments and your own keys survive byte for byte, with a backup kept beside the file.

No account, no cloud, no subscription, no telemetry. The parade fetches nothing from anywhere; your machine is the whole internet the ducks need.

The drawing editor

The drawing editor provides nineteen tools, eight colors, stroke-level undo, and autosaved drafts. F2 opens it straight from the parade; the Ctrl+Shift+D chord and the command line work too. Draw a duck, a balloon, a grass tile or a decoration, then assign your art to any of the sixteen parade slots, from the two leads to the five balloons.

Undo works in whole strokes, not single cells, and a draft of the drawing is saved a second after you stop, so even a crash costs at most one second of art.

Any picture becomes a balloon

Drop a picture into the balloons folder and a watcher inflates it without a restart. Type its name on the parade's own input line and it joins mid-march. Or point the command line at any image on disk. PNG, JPEG, GIF and BMP all work: the picture becomes ASCII art, mounted on a rope, and the next carrier duck walks it across the screen.

A message of your own can march above the grass, in the block font, fading out after eight seconds or staying forever if you cannot let it go.

Exports

The parade can be exported as a self-contained web page, an animated GIF, or an art package. The page is one file, about 650 kB for a twenty second loop, with no network, no assets and no fonts, that opens anywhere and can be paused and scrubbed. The parade is a pure function of a few numbers, so the same loop exports byte for byte the same file every time.

Open source, in Rust

AGnosis is a Rust workspace under the Annoying Goods Open Source License with Ethical Restrictions, with the simulation in a pure platform-free core that compiles for the browser target, and a test suite that stood at 1,090 tests on Windows at the last count. The release gate renders the parade headless twice and demands the two runs be byte-identical, and the browser build is type-checked on every push.

Three desks, three packages

The application has no account, telemetry, or network requirement. One self-contained binary per platform, with the font embedded inside it, so there are no runtime assets to install.
